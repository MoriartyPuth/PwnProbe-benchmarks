## Notes

- Behaviour preservation: every buildable lab recovers its flag via the same
  winning strategy as the pre-refactor baseline. `lab12_partial_overwrite` wins
  via `stack_overwrite` (the intended PR 6 ranking effect; flag still recovered).
- `lab07_ret2libc`: the strategy assumes the leak is `system()`'s runtime address
  (page-aligned base check), which does not hold under glibc 2.43; a matching
  `--libc` is the workaround. Robust libc fingerprinting is planned (roadmap §30,
  PR 20).
- `lab11_ret2syscall`: builds `-static`; install a static libc (`glibc-static` on
  Fedora) to run it.
- Timings are host-specific and vary run to run (`lab15_rop_chain` ranged
  ~424–482s across runs on this host); do not compare them to the `36acdbc`
  figures. Set any numeric threshold from numbers reproduced on the target host.
- `lab13_angr_logic` used `PWNPROBE_PYTHON` (angr 10.0.5; unicorn fast-path
  disabled, symbolic execution unaffected).

## Reproduce

```sh
git -C PwnProbes checkout d795894
( cd PwnProbes && go build -o bin/pwnprobe ./cmd/pwnprobe )
PWNPROBE_PYTHON=/path/to/angr-venv/bin/python \
  ./run.py --pwnprobe PwnProbes/bin/pwnprobe --wall 900 --out results/d795894.json
```

`lab11_ret2syscall` additionally needs a static libc (`glibc-static` on Fedora).
